Processo Bot · 4 Fluxos

Einstein Bot conversacional via WhatsApp

O cidadão interage via WhatsApp com o Einstein Bot que identifica a intenção (NLU 5 intents), coleta dados, consulta APIs SEFIN e retorna o DAM ou link.

Fluxos majoritariamente self-service — transbordo humano disponível via Omni-Channel/Service Console (E09, Business Hours 08h-17h seg-sex)

1. IPTU — 2ª via DAM

Cidadão envia CPF/CNPJ → Bot consulta API ConsultaImovel → Apresenta inscrições → Cidadão seleciona → Bot chama API EmitirDamUnico → Retorna PDF DAM + código barras + pesquisa satisfação

2. TMRSU — 2ª via DAM

Fluxo idêntico ao IPTU (mesmas APIs, mesmo loop multi-inscrição)

3. ISS — Link Portal

Cidadão envia CPF/CNPJ → Bot retorna link do Portal SEFIN (sem DAM emission — P-15)

4. Alteração Cadastral

Cidadão envia CPF/CNPJ → Bot consulta dados atuais → Apresenta 9 campos editáveis (nome, telefone, email, endereço completo) → Coleta alterações → Confirma → API Dados Cadastrais atualiza

Pesquisa satisfação obrigatória ao final de todos os fluxos (API CRM SEFIN fire-and-forget)
