Premissas e exclusões

O que assumimos verdadeiro — e o que explicitamente NÃO está no escopo

Premissas (assumimos)
  • Slack Enterprise Grid já contratado e provisionado
  • TI Dataprev fornece specs Swagger/OpenAPI + sandbox dos 7 legados na F0
  • Decisão de Workspace Slack (B2B segregado vs. único) travada na F0
  • Volumetrias auditadas na F0 — concurrent users, peak load, data volumes
  • AWS KMS master keys sob controle do CISO para o Slack EKM
  • Dataprev staffa 0% das roles técnicas (100% Salesforce PS)
Exclusões (NÃO fazemos)
  • Migração de dados históricos — apenas integração read/write via APIs
  • Customizações nos legados — integramos "as-is"
  • Treinamento dos 2.500 clientes B2B — Dataprev conduz; PS faz train-the-trainer
  • Licenças Salesforce — provisionadas separadamente
  • Migração para Service Cloud (E08 Clarity) — decision gate na F2; execução fora deste SOW se aprovada
